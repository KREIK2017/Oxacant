# Oxacant® Advertorial

Німецькомовний advertorial для **Oxacant® sedativ Liquid**, орієнтований переважно на аудиторію 50+. Сторінка побудована як редакційний health-матеріал: знайома життєва ситуація → самоперевірка → ознаки нервового навантаження → пояснення → статті → презентація продукту.

Проєкт є звичайним статичним сайтом на **HTML, CSS та JavaScript**. Збірка, npm-залежності або бекенд не потрібні.

## Швидкий старт

Робочі файли сайту знаходяться в папці `dist/`.

Для коректної роботи абсолютних посилань (`/article.css`, `/assets/...`, `/ratgeber/...`) сайт потрібно відкривати через локальний вебсервер, а не подвійним кліком по HTML-файлу.

Варіант із Node.js:

```bash
npx serve dist
```

Варіант із Python:

```bash
python -m http.server 8080 --directory dist
```

Після запуску відкрити адресу, яку покаже сервер, наприклад `http://localhost:8080`.

## Що редагувати

### Головна сторінка

Файл: `dist/index.html`

У ньому знаходяться:

- HTML усіх блоків головної сторінки;
- основні стилі всередині `<style>` у `<head>`;
- JavaScript квізу, вкладок статей, progress bar та інших інтерактивних елементів наприкінці документа.

Основні блоки сторінки:

1. Hero з заголовком «7 Anzeichen…».
2. Редакційний вступ і медичне застереження.
3. Інтерактивний Stress-Check із п’ятьма запитаннями.
4. Ознаки 01–04 у почергових блоках «фото + текст».
5. Ознаки 05–07 у компактних картках.
6. Mechanism-блок про зв’язок стресу з серцево-судинною системою.
7. Практичні кроки, які користувач може зробити самостійно.
8. Блок термінових медичних застережень.
9. Перехід від проблеми до рослинної підтримки.
10. Product reveal Oxacant® sedativ Liquid.
11. Чотири рослинні компоненти.
12. Дозування, безпека та аптечна доступність.
13. FAQ і фінальний CTA.
14. Темний інформаційний блок із перемикачем статей.
15. Джерела і Pflichtangaben.

### Зображення

Папка: `dist/assets/`

Якщо потрібно замінити фото без редагування HTML, найпростіше залишити ту саму назву файлу та ті самі пропорції. Нові вихідні матеріали спочатку можна зберігати в `source-assets/`, але для публікації потрібний файл необхідно перенести в `dist/assets/`.

### Статті

Готові дві окремі сторінки:

- `dist/ratgeber/herzstolpern-extrasystolen/index.html` — про Herzstolpern та Extrasystolen;
- `dist/ratgeber/druck-auf-der-brust-durch-stress/index.html` — про Druck auf der Brust через стрес і важливість медичної діагностики.

Обидві сторінки використовують спільний файл `dist/article.css`. Невеликий JavaScript progress bar знаходиться безпосередньо наприкінці кожної статті.

На головній у блоці Ratgeber передбачено чотири теми. Дві середні картки вже ведуть на готові статті. Для першої (`/ratgeber/nervoeses-herz/`) і четвертої (`/ratgeber/innere-unruhe/`) ще потрібно створити окремі сторінки.

Щоб додати нову статтю:

1. Скопіювати одну з наявних папок у `dist/ratgeber/` і дати новій папці URL-зрозумілу назву.
2. Оновити `<title>`, description, keywords, canonical, JSON-LD, H1, текст, джерела та внутрішні посилання.
3. Залишити підключення `/article.css` або доповнити цей файл спільними стилями.
4. У `dist/index.html` оновити відповідну вкладку `reading-tab` і панель `reading-panel`, додавши URL нової статті.
5. Додати взаємні посилання в секції `Weiterlesen` інших статей.
6. Перед публікацією передати медичні твердження, дозування, Pflichttext і product claims на медичну/юридичну перевірку.

## Важливі технічні деталі

- Основна мова контенту — німецька (`lang="de"`).
- Сайт адаптований під desktop, tablet і mobile.
- Шрифти `DM Sans` і `Newsreader` завантажуються з Google Fonts, тому для їхнього відображення потрібен інтернет.
- Внутрішні маршрути починаються з `/`, тому папка `dist` має бути коренем сайту.
- Якщо сайт розміщуватиметься не в корені домену, а в підпапці, абсолютні URL потрібно замінити або налаштувати base path.
- Основні CTA ведуть на офіційну сторінку Oxacant® на сайті Klein Naturarznei.
- `reference-board.html` — робочий матеріал, його необов’язково залишати у публічній production-версії.
- Папки `output/`, `tmp/`, `source-assets/` і файли ТЗ не потрібні для роботи опублікованого сайту.

## Що передати колезі

Для інтеграції або публікації достатньо передати всю папку **`dist/`**, не змінюючи її внутрішню структуру.

Якщо колезі також потрібен контекст проєкту, варто передати:

- `README.md` — ця інструкція;
- `TZ_OXACANT_ADVERTORIAL_UA.md` — повне технічне завдання;
- `REFERENCES.md` — список конкурентів і пояснення, звідки взяті UX-патерни;
- `source-assets/` — вихідні матеріали для подальших візуальних правок.
